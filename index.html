YouTube API key

This app uses Google's free YouTube Data API to look up channels. Your key is saved on this computer only.

How do I get a free key? (about 3 minutes, no card needed)
  1. Open Google Cloud Console and create a project (any name).
  2. Open YouTube Data API v3 and click Enable.
  3. Go to Credentials, then Create credentials and API key.
  4. Copy the key and paste it above, then press Save.
