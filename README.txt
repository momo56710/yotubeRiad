YOUTUBER FINDER (source folder)

This folder holds the app's source code. You build the program once, then use it.

1. WINDOWS: double-click build.bat
   (the first time it installs a small free tool called Deno, then asks you to run it again).
   MAC / LINUX: open a terminal here and run:  ./build.sh
2. When it says "Done", double-click YouTuberFinder.exe (Mac/Linux: ./YouTuberFinder).
3. Your browser opens the app. Add your free YouTube API key when it asks.

Full instructions, API key setup, and how to use Claude with it: open GUIDE.md
(Claude reads CLAUDE.md in this folder automatically).
